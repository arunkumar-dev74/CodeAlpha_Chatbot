# CodeAlpha_Chatbot

## About
This is an intermediate Python-based chatbot developed for the CodeAlpha Internship Task 4.

## Features
- Hello, Hi and Hallo greetings
- Hindi and English commands
- User name memory
- Current date and time
- Random jokes
- Exit command

## Technologies Used
- Python
- Random Module
- Datetime Module

## How to Run

python Chatbot.py
